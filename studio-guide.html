1 पहली बार की तैयारी (सिर्फ़ एक बार)

  1. Chrome या Edge में स्टूडियो खोलें।
  2. ऊपर दाईं ओर “GitHub: not connected” पर क्लिक करें।
  3. वहाँ दिए लिंक से GitHub में Fine-grained token बनाएँ:
    • Repository access → Only select repositories → Zindagi-with-Sachin
    • Permissions → Contents: Read and write (और कुछ नहीं)
  4. token कॉपी करके स्टूडियो में पेस्ट करें → Save & check। ऊपर हरा बिंदु और आपका नाम दिखेगा।

🔒 token एक चाबी है — इसे किसी को न भेजें, स्क्रीनशॉट में न दिखाएँ। यह सिर्फ़ आपके ब्राउज़र में रहता है।

💡 हमेशा एक ही कंप्यूटर और एक ही ब्राउज़र से रिकॉर्ड करें — अधूरी रिकॉर्डिंग उसी ब्राउज़र में सुरक्षित रहती है।

2 अध्याय (स्क्रिप्ट) लिखना

  1. लेखन डेस्क → “Audiobook chapters (scripts)” → नया अध्याय।
  2. भरें: शीर्षक, अध्याय नंबर (1, 2, 3…), किताब का नाम, छोटा विवरण और स्क्रिप्ट।
  3. Save करें → लगभग 1 मिनट में स्टूडियो की बाईं सूची में आ जाएगा (⟳ दबाएँ)।

💡 छोटे पैराग्राफ़ लिखें। कठिन शब्दों पर पहले से अभ्यास कर लें। ## शीर्षक लिखने से स्क्रिप्ट में सुनहरा उप-शीर्षक बनता है।

3 रिकॉर्डिंग से पहले — चेकलिस्ट

4 रिकॉर्डिंग करना

  1. बाईं ओर अध्याय चुनें → ● Record टैब।
  2. A+ / A− से अक्षर बड़े-छोटे करें। चाहें तो Teleprompter scroll चालू करें — स्क्रिप्ट अपने-आप सरकेगी (स्लाइडर से गति)।
  3. ● Record दबाएँ (पहली बार माइक के लिए Allow करें)। नीचे की हरी पट्टी बोलते समय बीच तक जाए — लाल तक नहीं।
  4. पढ़ते समय:
    • Space = रुकें / फिर शुरू
    • गलती हुई? M दबाएँ → 2 सेकंड रुकें → वही वाक्य दोबारा पढ़ें। रिकॉर्डिंग बंद न करें।
    • Ctrl + S = सेव (हर सेकंड अपने-आप भी सेव होता है)
  5. ब्रेक चाहिए? Pause करके टैब बंद कर दें। अगली बार पूछेगा “Resume paused draft?” → Resume recording।
  6. अध्याय पूरा → ■ Stop। रिकॉर्डिंग Draft Ready बन जाती है।

💡 हर अध्याय एक जैसे शुरू करें: “ज़िंदगी विद सचिन — अध्याय एक: मेरी पहली यात्रा।” और अंत में 2 सेकंड चुप रहें।

5 एडिटिंग (✂ Edit टैब)

कामकैसे
गलती वाला वाक्य हटानालाल ⚑ निशान पर ✕ cut — फिर ▶ Play से सुनकर जाँचें
कोई भी हिस्सा हटानाwaveform पर माउस से खींचकर चुनें → Delete
सिर्फ़ चुना हिस्सा रखनाचुनें → Trim to selection
एक वाक्य दोबारा बोलनावह हिस्सा चुनें → ● Record patch → बोलें → ■ Stop patch
बीच में कुछ जोड़नाकर्सर रखें → ● Record patch या Insert file
लंबे विराम छोटे करनाTighten pauses (एक क्लिक)
गलती हो गईCtrl+Z (वापस), Ctrl+Shift+Z (फिर से)

💡 एडिटिंग के बाद पूरा अध्याय एक बार हेडफ़ोन से सुनें। अगले दिन ताज़े कानों से सुनना और भी अच्छा।

6 आवाज़ की क्वालिटी

दाईं ओर Voice processing कार्ड में ये चार चीज़ें हैं:

सेटिंगक्या करती हैक्या चुनें
Normalize loudnessपूरी आवाज़ को सही ज़ोर पर लाती हैहमेशा चालू। YouTube/Spotify/वेबसाइट → −16, Audible → −20
Voice sound NEWआवाज़ को रेडियो जैसा भरा और साफ़ बनाती है (EQ, “स” की तीखापन कम, आवाज़ एक-सार)Warm narrator (ज़्यादातर के लिए सबसे अच्छा)। पतली आवाज़ लगे → Deep radio voice। भारी/धुंधली लगे → Clear & bright
Soften breaths NEWवाक्यों के बीच की साँस और होंठों की आवाज़ धीमीचालू रखें
Noise reductionपीछे की हल्की सरसराहट कमसिर्फ़ तब, जब पंखे/AC की आवाज़ आए

जाँच: Measure दबाएँ → सब हरा और ACX check: PASS = प्रोफ़ेशनल क्वालिटी। फिर ▶ Preview mix से हेडफ़ोन पर सुनें।

💡 Noise floor लाल हो (−60 से ऊपर) तो कमरा और शांत करें — मशीन से ज़्यादा फ़र्क कमरे से पड़ता है।

7 बैकग्राउंड म्यूज़िक और इफ़ेक्ट

  1. Add background → म्यूज़िक चुनें: Tanpura drone (आध्यात्मिक), Calm pad (शांत), Rain / Wind (प्रकृति) — या Upload music… से अपना।
  2. Volume → 8% से शुरू करें। म्यूज़िक आपकी आवाज़ के हिसाब से अपने-आप मिलाया जाता है, इसलिए हर ट्रैक पर 8% एक जैसा लगेगा।
  3. Auto-duck चालू रखें — आप बोलेंगे तो म्यूज़िक धीमा, रुकेंगे तो हल्का ऊपर।
  4. Stereo music चालू रखें — म्यूज़िक चौड़ा और भरा सुनाई देता है (हेडफ़ोन पर फ़र्क साफ़)।
  5. ▶ Preview mix → शुरुआत से सुनें: पहले 3 सेकंड सिर्फ़ म्यूज़िक, फिर आपकी आवाज़, अंत में 4 सेकंड म्यूज़िक धीरे बंद।

Sound effects: इफ़ेक्ट चुनें (मंदिर की घंटी, पन्ना पलटना, दिल की धड़कन…) → समय लिखें (जैसे 2:15) → + Add at time, या कर्सर पर + At cursor।

💡 म्यूज़िक सुनाई ही न दे → वॉल्यूम 10–12% करें। आवाज़ दबती लगे → 5–6% करें। कहानी की आवाज़ हमेशा सबसे ऊपर।

8 ड्राफ़्ट सँभालना

  • 💾 Save draft → हर बार नया वर्ज़न (v1, v2, v3…) GitHub पर सुरक्षित। कुछ खोता नहीं।
  • 🗂 Drafts → सब अध्यायों की स्थिति: Paused · Draft Ready · Edited · Ready for Upload
  • दूसरे कंप्यूटर पर → Edit टैब → Load draft from GitHub।
  • Re-record → अध्याय शून्य से फिर शुरू (GitHub पर पुराने वर्ज़न रहते हैं)।
  • 🗑 Delete NEW → बेकार/पुराना ड्राफ़्ट इस कंप्यूटर से हटाएँ। पहले पूछेगा, फिर हमेशा के लिए हटेगा। GitHub या वेबसाइट पर डला हुआ नहीं हटता।

9 फ़ाइनल करना — “Make Ready for Upload”

  1. दाईं ओर नीचे छोटा विवरण लिखें, Cover image चुनें (चौकोर, 1400×1400 या बड़ा)।
  2. ✔ Make Ready for Upload दबाएँ। स्टूडियो अपने-आप:
    • MP3 बनाता है — 192 kbps, 44.1 kHz (म्यूज़िक हो तो स्टीरियो, वरना mono) — Audible/Spotify वाली क्वालिटी
    • नाम, लेखक, किताब, अध्याय नंबर और कवर फ़ाइल के अंदर डालता है
    • ACX जाँच करता है और audiobook/final/ में GitHub पर सेव करता है
    • “Also publish on the website” चालू हो तो अध्याय वेबसाइट, Spotify/Apple फ़ीड और “साथ-साथ पढ़ें” में अपने-आप आ जाता है
  3. चेकलिस्ट में सब ✅ → ⤓ Download MP3।

▶ YouTube पर डालना — सबसे आसान तरीका

YouTube सिर्फ़ ऑडियो नहीं लेता, उसे वीडियो चाहिए। स्टूडियो यह खुद बना देता है।

  1. अध्याय एडिट करके दाईं ओर नीचे 🎬 Prepare for YouTube दबाएँ।
  2. फ़ोटो चुनें (न चुनें तो किताबों वाली आपकी फ़ोटो लगेगी) और Playlist देख लें — अध्याय की श्रेणी से अपने-आप चुनी जाती है।
  3. शीर्षक, विवरण और टैग पहले से तैयार मिलेंगे — चाहें तो बदलें।
  4. 🎬 Make video + thumbnail दबाएँ। स्टूडियो बनाता है:
    • वीडियो (720p) — आपकी फ़ोटो, अध्याय का नाम, आवाज़ के साथ नाचती सुनहरी लहरें और समय-पट्टी
    • थंबनेल (1280×720) — बड़ा शीर्षक, “🎧 ऑडियोबुक · अध्याय”, लहरें और “सुनिए · सीखिए · आगे बढ़िए”
    30 मिनट का अध्याय बनने में कुछ मिनट लगते हैं — टैब खुला रखें।
  5. फिर दो में से एक:
    • ⇪ Upload to YouTube (एक क्लिक — नीचे वाली एक बार की सेटिंग के बाद) — वीडियो, थंबनेल, शीर्षक, विवरण और प्लेलिस्ट सब अपने-आप।
    • या ⤓ Video और ⤓ Thumbnail डाउनलोड करें → Open YouTube Studio → फ़ाइल डालें → 📋 Copy बटन से शीर्षक/विवरण चिपकाएँ → प्लेलिस्ट चुनें → Public।

💡 Google Chrome या Microsoft Edge इस्तेमाल करें — वीडियो बनाना इन्हीं में चलता है। वीडियो सही प्लेलिस्ट में गया तो वह वेबसाइट के वीडियो पेज पर भी अपने-आप दिखेगा।

एक-क्लिक अपलोड की एक बार की सेटिंग (लगभग 15 मिनट)

  1. Google Cloud Console खोलें (उसी Google खाते से जिससे YouTube चैनल है) → नया प्रोजेक्ट: Zindagi Studio।
  2. APIs & Services → Library → YouTube Data API v3 खोजें → Enable।
  3. Google Auth Platform / OAuth consent screen → External → App name: Zindagi Studio, अपना ईमेल डालें → Save।
  4. Audience → Test users → Add users → अपना वही Google ईमेल जोड़ें।
  5. Clients → Create client → Web application → Authorized JavaScript origins में डालें: https://zindagi-with-sachin.vercel.app → Create।
  6. जो Client ID मिले (…apps.googleusercontent.com), उसे कॉपी करें।
  7. स्टूडियो में ऊपर GitHub बटन → नीचे Optional · direct YouTube upload में पेस्ट करें → Save & check।

⚠️ YouTube का नियम: ऐसे नए टूल से डाला गया वीडियो पहले Private रहता है (जब तक Google टूल की जाँच न कर ले)। अपलोड के बाद स्टूडियो में दिखे लिंक से YouTube Studio खोलें → Visibility → Public — बस एक क्लिक। अपना थंबनेल लगाने के लिए चैनल verify होना चाहिए।

💡 Client ID कोई पासवर्ड नहीं है, पर इसे फिर भी किसी को भेजने की ज़रूरत नहीं। Google में लॉगिन हमेशा आप खुद करेंगे।

📱 Shorts / Reels बनाना NEW

छोटे खड़े वीडियो सबसे ज़्यादा नए लोगों तक पहुँचते हैं। हर अध्याय से 1–3 Shorts बनाइए।

  1. ✂ Edit टैब में waveform पर माउस से खींचकर अपनी सबसे अच्छी 20–60 सेकंड की लाइनें चुनें।
  2. दाईं ओर नीचे 📱 Make a Short दबाएँ। समय अपने-आप भर जाएगा। ▶ Listen to clip से सुन लें।
  3. Captions बॉक्स में वही शब्द रखें जो आप उस हिस्से में बोलते हैं (अंदाज़े से भरे होते हैं — एक बार ठीक कर दें)।
  4. 🎬 Make vertical video → वीडियो बनकर दिखेगा → ⤓ Download video।
  5. फ़ोन से उसी फ़ाइल को YouTube Shorts, Instagram Reels और Facebook Reels पर डालें। विवरण में #Shorts #audiobook और पूरे अध्याय का लिंक लिखें।

💡 सबसे अच्छा Short: पहली ही लाइन में सवाल या चौंकाने वाली बात। 30–45 सेकंड सबसे बढ़िया चलते हैं।

वेबसाइट अब एक पॉडकास्ट फ़ीड बनाती है: zindagi-with-sachin.vercel.app/feed.xml। इसे एक बार इन जगहों पर जोड़ दें — उसके बाद हर नया अध्याय (जो वेबसाइट पर पब्लिश हुआ) वहाँ अपने-आप आएगा।

  1. पहले: कम से कम एक अध्याय “Make Ready” से वेबसाइट पर पब्लिश करें (खाली फ़ीड कोई नहीं लेता)।
  2. ईमेल डालें: लेखन डेस्क (Pages CMS) → Podcast settings → Owner e-mail में अपना ईमेल → Save। Spotify इसी पर कोड भेजता है।
  3. Spotify: creators.spotify.com → Get started → “I already have a podcast” / Find an existing show → ऊपर वाला feed लिंक पेस्ट करें → ईमेल पर आया कोड डालें।
  4. Apple Podcasts: podcastsconnect.apple.com → + New Show → Add a show with an RSS feed → feed लिंक पेस्ट करें।
  5. YouTube Music, Amazon Music, JioSaavn भी इसी feed लिंक से जुड़ते हैं।
  6. Google सर्च: Google Search Console → वेबसाइट जोड़ें → Sitemaps → sitemap.xml लिखकर Submit।

🔒 ये खाते आप खुद बनाएँ और लॉगिन खुद करें। ईमेल सार्वजनिक फ़ीड में दिखता है — चाहें तो इसके लिए अलग ईमेल रखें।

📅 रोज़ का प्रोफ़ेशनल तरीका

  1. दिन में 1–2 अध्याय — सुबह, जब आवाज़ ताज़ा हो।
  2. हर दिन कमरा, माइक और दूरी एक जैसी — ताकि सब अध्याय एक जैसे सुनाई दें।
  3. रिकॉर्ड → गलतियाँ काटें → Measure → Save draft।
  4. अगले दिन एक बार सुनें → छोटे सुधार → Make Ready।
  5. पूरी किताब होने पर सब अध्याय एक साथ अपलोड करें।

❓ सवाल-जवाब

ब्राउज़र बंद हो गया / बिजली चली गई — रिकॉर्डिंग गई?

नहीं। हर सेकंड सेव होता है। उसी ब्राउज़र में स्टूडियो खोलें → “Resume paused draft?” → Resume या “Finish as draft”।

माइक काम नहीं कर रहा

एड्रेस बार में ताले 🔒 पर क्लिक करें → Microphone → Allow → पेज रीलोड करें। Windows में Settings → Privacy → Microphone भी चालू हो।

“GitHub: token invalid” दिख रहा है

token की समय-सीमा खत्म हो गई होगी। GitHub में नया token बनाकर स्टूडियो में फिर पेस्ट करें (कदम 1)।

कितना लंबा अध्याय रिकॉर्ड कर सकते हैं?

आराम से 30–60 मिनट। इससे लंबा हो तो दो अध्यायों में बाँटें — सुनने वालों के लिए भी आसान।

ACX check FAIL हो रहा है

RMS लाल → “−20 LUFS (ACX safe)” चुनें। Noise floor लाल → Noise reduction चालू करें और कमरा शांत करें। Peak लाल → फिर Measure करें (स्टूडियो अपने-आप ठीक करता है)।

दूसरे कंप्यूटर / मोबाइल पर काम कर सकते हैं?

हाँ — Save draft के बाद दूसरे कंप्यूटर पर Edit टैब → “Load draft from GitHub”। मोबाइल पर देख सकते हैं, पर रिकॉर्डिंग कंप्यूटर पर बेहतर होती है।
