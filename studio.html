      Connect GitHub

      The studio saves drafts and final MP3s straight into Kumar3216549/Zindagi-with-Sachin. It needs a GitHub token once. The token stays only in this browser.

      1. Open GitHub → Fine-grained token.
      2. Name: Audiobook Studio. Expiration: up to you (e.g. 1 year).
      3. Repository access → Only select repositories → Zindagi-with-Sachin.
      4. Permissions → Repository → Contents: Read and write. Nothing else.
      5. Generate, copy the token and paste it here.

      Optional · your upload API

      If you have a server that accepts the final file, enter its URL. The studio sends a POST with form fields file, title, description, chapter.

      Optional · direct YouTube upload

      Paste your Google OAuth Client ID (one-time setup — steps in the guide). Without it you can still make the video and thumbnail and upload them yourself.
